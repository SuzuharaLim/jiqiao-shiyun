## 新增畫面步驟

1. 建 `src/screens/Foo.jsx`（用 `<TopBar title/onBack>` + `<div className="body">`）。
2. `registry.jsx`：`import Foo` → `SCREENS` 加 `foo: Foo`。
3. 從他處 `push('foo', props)` 進入；若是敏感動作先 `if(!requireAccount('...')) return`。
