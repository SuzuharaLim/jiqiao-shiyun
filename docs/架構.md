# 架構總覽

> 前端 Vite+React SPA + 後端 Express 全端。無 react-router、無 Redux。
> 快速入口見根目錄 [CLAUDE.md](../CLAUDE.md)。
>
> ⚠️ **現況更新（以 CLAUDE.md 為準）**：資料庫已改 **PostgreSQL（Cloud SQL）/ SQLite 雙驅動**（非純 SQLite）；社群內容**已資料庫化**（非 mock）；路由改為**每畫面一個網址**（History API 同步，非單一 URL）；已部署 Cloud Run 並綁 `chengqi.tw`。下方部分敘述早於這些改版，最新架構與端點請見 CLAUDE.md 與 `API-總表.md`。

## 技術棧

- **前端**：React 18、Vite 5、`@vitejs/plugin-react`。純 CSS（`styles.css`，token 驅動），無 CSS 框架、無 UI 套件。
- **後端**：Express 4、better-sqlite3（同步）、bcryptjs、cookie-parser、express-rate-limit、helmet。
- **建置**：`vite build` → `dist/`。正式 `node server/index.js` 同時 serve `dist/` + `/api`。

## 分層

```
瀏覽器
 └─ index.html → public/theme-init.js（先套主題）→ src/main.jsx
     └─ <ErrorBoundary>            錯誤邊界（componentDidCatch）
         └─ <NavProvider>          全域 Context（狀態 + 動作）
             └─ <App>              框架：路由渲染 + 桌機 chrome
                 ├─ <WebNav/>      ≥900px 頂部導覽列
                 ├─ .device
                 │   ├─ <Auth/>            未登入
                 │   └─ .rootpane          已登入
                 │       ├─ ROOTS[tab]     5 大分頁根畫面
                 │       └─ .screen        stack 堆疊（詳情）畫面
                 ├─ <WebFooter/>   ≥900px 頁尾
                 └─ <AuthWall/>    登入牆
```

## 啟動生命週期

1. `theme-init.js`：React 掛載前讀 `localStorage('jq-theme')` 套上 `data-theme`，避免深色使用者看到白閃。
2. `main.jsx`：`createRoot` 掛 `<ErrorBoundary><NavProvider><App/>`（含 `React.StrictMode`）。
3. `NavProvider` 啟動時打 **`GET /api/me`** 還原登入態：
   - 成功 → `setUser(...)` + `setCsrf(csrfToken)`；`authLoading=false`。
   - 401/失敗 → `user=null`。
   - `App` 在 `authLoading` 時顯示 `.auth-splash`；`!user` 顯示 `<Auth/>`（守門）；否則進主 App。
4. 若網址是 `/verify-email?token=...`，`nav.jsx` 的 `useEffect` 打 `POST /api/verify-email` 後清 URL。

## 路由模型（tab + stack）

- **狀態**：`tab`（0–4，目前分頁）、`stack`（`[{screen, props}]`，堆疊畫面）。都在 `nav.jsx`。
- **對照表**：`src/screens/registry.jsx`
  - `ROOTS = [Feed, Explore, Create, Almanac, Profile]`（依 tab index）。
  - `SCREENS = { key: Component }`（堆疊畫面）。
- **動作**：`setTab(i)` 清 stack 換分頁；`push(screen, props)` 疊畫面；`pop()` 退一層；`popAll()` 清空。四者皆 `window.scrollTo(0,0)`。
- **整站單一 URL `/`**：深層連結/重新整理一律回首頁（SPA fallback 回 `index.html`，狀態重置）。沒有 per-screen URL。

## 資料流

- **全域互動狀態**：集中在 `nav.jsx` 的單一 Context（見 [狀態與資料.md](狀態與資料.md)）。任何跨畫面共享狀態（購物車、訂單、追蹤、餘額、偏好…）都在此，畫面用 `useNav()` 取用。
- **示範資料**：靜態 `import` 自 `src/data/mock.js`（隨 bundle 一次載入，非 fetch）。
- **農民曆**：`src/data/almanac.js` 以錨點 6/6 用偏移量**確定性生成**任意日頁（`dayFor(off)`、`monthCells(y,m)`）。
- **認證**：真後端。前端經 `src/api.js`（`fetch` + `credentials:'include'` + `x-csrf-token`）打 `/api/*`；session 在 HttpOnly Cookie（JS 讀不到），只把非敏感 csrf token 存記憶體。

## 桌機 chrome（≥900px）

- `WebNav.jsx`：頂部導覽列（logo、5 分頁、通知🔔/私訊✈/主題/使用者→設定/登出）。取代底部 `.tabbar` 與各根畫面自帶頂列。
- `WebFooter.jsx`：頁尾（品牌、連結、版權）。
- 版面細節見 [樣式與RWD.md](樣式與RWD.md)。

## 部署

- `Dockerfile`：全端（node build → node runtime，非 root，serve dist + /api）。
- env：`APP_URL`、`DATA_DIR`、`PORT`、`NODE_ENV`（見 `.env.example`）。
- Cloud Run 細節與限制見 `docs/部署-CloudRun.md`。`netlify.toml`/`public/_redirects` 在 Cloud Run 無效。
