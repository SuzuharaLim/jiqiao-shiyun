# 機巧時運 · App 使用說明

> 給「使用者」的操作教學。（部署／維運請看 `docs/操作手冊.md`。）
> 測試帳號：一般 `newuser@example.com` / `secret12345`；管理者 `admin@jiqiao.local` / `admin12345（僅本機；正式站密碼由 ADMIN_PASSWORD 指定或隨機產生）`。

---

## 1. 進入與帳號

- **註冊**：點「免費註冊」→ 填暱稱、**自訂帳號 handle**（公開、不可重複，輸入時即時顯示是否可用）、Email、密碼。
- **Email 驗證**：註冊後上方會出現「請驗證 Email」橫幅，點「重寄驗證信 → 完成驗證」即可（示範環境把信件連結就地顯示）。
- **登入 / 忘記密碼**：一般登入；忘記密碼走 Email 重設連結。
- **訪客**：點「訪客先逛逛」可免註冊瀏覽；但下單、發文、按讚等需要真帳號（會跳登入牆）。

> 每個畫面都有自己的網址（例如掃描是 `/AR`、貼文是 `/post/貼文id`），可直接分享或用瀏覽器上一頁/下一頁。

## 2. 今日曆頁（首頁 🏠）

- **翻日**：用日期左右的 `‹ ›` 翻前後一天；點中間日期可跳到任一天（月曆選擇器）。App 預設停在**真實今日**，翻走後可按「↩ 回今日」。
- **今日曆頁卡**：干支、節氣、宜／忌、吉時、每日一諺。
- **看完整農民曆**：點「📜 看完整農民曆」→ 進**完整曆頁**：三柱干支、建除十二神、二十八星宿、彭祖百忌、每日胎神、沖煞（含虛歲歲數）、喜／財／貴神方位、十二時辰吉凶、特殊日。
- **今日大家拍的**：右側/下方是當前節氣的社群作品，點「更多作品」看整本相簿。

## 3. 社群：探索 🔍 與貼文

- **探索**：搜尋節氣/植物/創作者、用節氣輪篩選、看作品市集（點作品看詳情、可購買授權）、看人氣創作者、參加節氣攝影挑戰與排行榜。
- **貼文詳情**：可**按讚 ❤️**、**留言**、**追蹤**作者、「加入月曆」收藏。讚數與留言都是**真實存資料庫**、會持久化。
- **通知**：鈴鐺看互動通知（誰讚你、作品被選用、分潤入帳、神佛誕辰提醒…）。

## 4. 建立 ➕：相機工作室

點「建立 → 開啟相機」進入**相機工作室**（全程用瀏覽器相機，需允許相機權限；手機體驗最完整）：

- **拍攝**：**單點快門＝拍照**，**長按＝錄影**；右上可切換前後鏡頭。
- **版面**：選 2／3／4／6 格，連拍後自動拼貼成一張。
- **建立（限動）**：不用照片也能做——選純色/漸層背景 ＋ 打字、加**票選／問答／倒數**貼紙。
- **拍完檢視**：
  - **滑動濾鏡**：在照片上左右滑，套經典色調（Paris／Oslo／Tokyo…）。
  - **經典濾鏡**：切到「經典濾鏡」分頁（Clarendon／Gingham／Juno…），**再點一下同一個濾鏡**可叫出**強度滑桿（0–100）**微調。
  - **特效庫**：點濾鏡列最右的 🔍 進特效大觀園，搜尋美顏、貓耳、雀斑、變形等（臉部效果為近似疊加）。
  - **搖晃顯影**：開「📳 搖晃顯影框」→ 照片先模糊，**搖手機**逐漸顯影（桌機可點「模擬搖晃」）。
  - **動態文字**：點右上「Ａ」加文字，選打字機／卡拉OK／霓虹彈跳等動態字體。
- **發貼文（打字）**：也可走「發貼文」選圖、標節氣、**新增地點**、設定授權價上架市集。

> **新增地點**：點「📍 新增地點」→ 可**搜尋地點**、用**目前位置**（GPS）、看**地圖預覽**，並把常去的地方**存為常用**。

## 5.5 節氣卡片 AR 📷

拿到官方節氣卡片後，到 **AR 掃描**（`/AR`）用鏡頭對著它，卡上的物件會浮出 3D 角色，
瞄準卡面上不同的圖案會跳出對應內容（當令農產、身體保健、曆頁、應景食物、花期…），
答對小挑戰可以拿節氣徽章，並存成一張分享圖卡。

**沒有卡片也能看**：`/ar/card/2027-xiaohan` 有完整的卡面與熱區，用點擊代替鏡頭。

### 掃不到的時候

偵測靠的是**紙與桌面的邊界**，所以環境比技巧重要：

| 做這件事 | 為什麼 |
| --- | --- |
| 把卡片放在**深色桌面**上 | 卡片四周是白邊，放在淺色桌面上「紙與桌面的界線」根本不存在——這時**換角度不會有幫助** |
| 讓**整張**卡片入框，佔畫面一半以上 | 缺一個角就抓不到；太小則細節不足 |
| 找亮一點的地方，對穩 | 太暗或手震會讓比對分數不足 |
| 用**主鏡頭**，不要用超廣角（0.5×） | 超廣角的桶狀畸變會把卡片的直邊弓成弧線 |

還是不行就按頁面上的「**掃描診斷**」。它會列出可觀測的事實（選到哪顆鏡頭、有沒有
找到四邊形、卡片佔畫面幾 %、比對分數 vs 門檻、偵測到的長寬比），並針對**當下這一種**
失敗給出下一步——四種失敗的處理方式完全不同，猜錯只會白繞：

- **找不到四邊形** → 邊界問題，換深色桌面
- **框到的長寬比不對** → 框到的不是卡片（常見是整個螢幕或桌墊），靠近一點
- **是卡片但分數不足** → 光線／角度／鏡頭
- **卡片佔畫面太小** → 靠近

> **⚠️ 用螢幕上的圖來測**（還沒拿到實體卡時）：一定要**靠近到螢幕邊框落在取景框外面**，
> 否則系統會把「整個螢幕」當成要辨識的矩形，怎麼喬都不會成功。
> 卡片頁的「放大給另一台裝置掃描」會把圖放在深色滿版底上，並列出這幾個條件。

## 7. 管理後台（版主／管理者）

以 `admin@jiqiao.local` 登入 → **設定 → 管理後台**：

- **使用者・角色**（管理者）：調整每位使用者角色（一般／創作者／版主／管理者）。
- **內容 CMS**（版主以上）：直接編修濾鏡、特效、漸層、字體、諺語、神佛、節氣等清單的 JSON，**存檔後前端下次載入即生效**——不用改程式。

## 常見問題

- **相機打不開？** 需在瀏覽器允許相機權限，且網站須為 HTTPS（正式站 `chengqi.tw` 已是）。開不了也能用「建立」模式做純文字限動。
- **按讚/留言/貼文會保存嗎？** 會，都寫進雲端資料庫（Cloud SQL），換裝置登入也還在。
- **AI 顧問回覆很制式？** 代表尚未接上 GPT 金鑰（走示範腳本）；接上後即為真 AI（設定見 `docs/操作手冊.md`）。
