> 前端經 `src/api.js` 打 `/api/*`。既有更深文件：`docs/登入需求-後端安全設計.md`、`docs/登入需求-前端整合.md`、`docs/登入需求-落實對照.md`。

## 檔案

| 檔案 | 內容 |

## 常數（`index.js`）

`SESSION_MS`=7 天、`LOCK_THRESHOLD`=5 次、`LOCK_MINUTES`=15 分、`BCRYPT_COST`=12、`DUMMY_HASH`（查無此人也跑假 bcrypt，防時間側錄）。
Cookie：`{httpOnly:true, secure:isProd, sameSite:'strict', path:'/', maxAge:7d}`，名稱 `sid`。
速率限制：auth 端點 `authLimiter` 12 次/15 分；全域 `/api` 300 次/15 分。
`app.set('trust proxy', 1)`（Cloud Run 反向代理後取真實 IP/https）。

## 中介層

- **Session**：每請求讀 `sid` cookie → 查 `sessions`（未過期）→ 掛 `req.user`/`req.session`；過期則刪。
- `requireAuth`：無 `req.user` → 401。
- `requireCsrf`：`x-csrf-token` header 需 timing-safe 等於 `session.csrf_token`，否則 403。
- `requireRole(role)`：RBAC，角色不符 → 403。
- `helmet`：CSP（`scriptSrc 'self'` — 內嵌 theme script 已外移；`styleSrc` 含 `'unsafe-inline'` 給 React 行內 style；`imgSrc 'self' data:`）、HSTS 等。

## DB Schema（`db.js`，WAL、`foreign_keys=ON`）

- **users**：`id`(UUID PK)、`email`(UNIQUE)、`name`、`password_hash`(bcrypt)、`role`(預設 user)、`email_verified_at`、`failed_login_count`、`locked_until`、`last_login_at`、`created_at`、`updated_at`。
- **sessions**：`id`(隨機 256-bit PK)、`user_id`(FK CASCADE)、`csrf_token`、`ip`、`user_agent`、`expires_at`、`created_at`。
- **tokens**：`id`、`user_id`(FK CASCADE)、`kind`(`email_verify`/`password_reset`)、`token_hash`(只存 SHA-256)、`expires_at`、`used_at`、`created_at`。
- **audit_log**：`id`(AUTOINC)、`event`、`user_id`、`ip`、`user_agent`、`detail`、`created_at`。
- 索引：`sessions(user_id)`、`tokens(user_id)`、`users(email)`。

## 安全設計重點

bcrypt cost12（永不存明文）、伺服器端 session（Cookie 只帶不可猜的 sid）、登入即發新 session id（防 fixation）、HttpOnly+Secure(prod)+SameSite=Strict、CSRF double-submit（header vs session token，timing-safe）、統一錯誤 + 假 bcrypt 防列舉、帳號鎖定、速率限制、參數化查詢、helmet CSP/HSTS、RBAC、GDPR 刪帳/匯出、token 只存 hash 且時效一次性。

## 前端用戶端（`src/api.js`）

- `req()`：`fetch('/api'+path, {credentials:'include'})`；非 GET 帶 `x-csrf-token`（`setCsrf(t)` 設定，存記憶體非敏感）。非 2xx 丟含 `status`/`data` 的 Error。
- `api.{me,register,login,logout,logoutAll,sessions,forgot,reset,changePassword,verifyEmail,deleteAccount}`。

## 開發 vs 正式

- **開發**：`npm run dev`(5173) + `npm run dev:server`(8080)；Vite proxy `/api`→8080（同源 Cookie 正常）。
- **正式**：`npm run build` 後 `node server/index.js`；偵測 `dist/` 存在即 serve 靜態 + SPA fallback（非 `/api` 回 `index.html`）。
- Email：dev 只 log 連結（回 `devLink`）；正式需接真 SMTP。

## 已知限制

- **SQLite 在 Cloud Run `/tmp` 會重置、多實例不共享 session** → 正式需 Cloud SQL/Redis。
- 金流為模擬。社群登入（Google/LINE/Apple）的假按鈕已於 2026-07 移除，目前僅 Email 註冊/登入。寄信已可正式化（見 docs/寄信-Email設定.md）。
