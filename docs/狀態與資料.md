# 狀態與資料

> 全域狀態在 `src/store/nav.jsx`（單一 Context，`useNav()`）；示範資料在 `src/data/mock.js`。

## `nav.jsx` — Context API（`const { ... } = useNav()`）

### 主題
| 名稱 | 型別 | 說明 |
| --- | --- | --- |
| `theme` | `'light'\|'dark'` | 目前主題（持久化 `localStorage('jq-theme')`） |
| `toggleTheme()` | fn | 切換淺/深色 |

### 使用者 / 認證（真後端）
| 名稱 | 說明 |
| --- | --- |
| `user` | `{name,handle,email,role,emailVerified,guest}` 或 `null`（未登入）。由 `/api/me` 還原。 |
| `authLoading` | 啟動打 `/api/me` 期間為 `true`（`App` 顯示 splash）。 |
| `login(apiUser, csrfToken)` | 登入/註冊成功後由 `Auth` 呼叫，設 user + csrf。 |
| `loginGuest()` | 訪客模式：`{name:'訪客',guest:true,role:'guest'}`（不打 API）。 |
| `logout()` | 打 `/api/logout`（非訪客）、清 user/stack/tab。 |
| `updateProfile(patch)` | 本機合併 profile 欄位（暱稱/簡介/頭像）。 |

### 登入牆
| 名稱 | 說明 |
| --- | --- |
| `authWall` | `null` 或動作說明字串；非 null 時 `AuthWall` 彈出。 |
| `setAuthWall(v)` | 手動開關。 |
| `requireAccount(reason)` | **守門**：訪客/未登入回 `false` 並 `setAuthWall(reason)`；已登入回 `true`。敏感動作前呼叫：`if(!requireAccount('下單')) return`。 |

### 路由（tab + stack）
| 名稱 | 說明 |
| --- | --- |
| `tab` / `setTab(i)` | 目前分頁 0–4；`setTab` 清 stack 換分頁 + 捲頂。 |
| `stack` | `[{screen,props}]` 堆疊。 |
| `push(screen, props)` | 疊畫面 + 捲頂。 |
| `pop()` / `popAll()` | 退一層 / 清空 + 捲頂。 |

### 互動狀態（示範用，未持久化除非註明）
| 名稱 | 型別 | 說明 |
| --- | --- | --- |
| `liked` / `toggleLike(id)` | `{postId:bool}` | 貼文讚 |
| `saved` / `toggleSave(id)` | `{postId:bool}` | 加入月曆素材 |
| `reminders` / `toggleReminder(id)` | `{deityId:bool}` | 神佛提醒（種 `mazu/tudi`） |
| `subscribed` / `setSubscribed(b)` | bool | Premium 訂閱 |
| `cart` / `addToCart(item)` / `clearCart()` | `[{id,name,price}]` | 購物車（去重） |
| `orders` / `addOrder(order)` | `[{id,date,items,total,status,pay}]` | 購買紀錄（種 2 筆示範 `JQ-*`） |
| `projectPhotos` / `togglePhoto(id)` | `{id:bool}` | 做月曆選圖 |
| `following` / `toggleFollow(user)` / `followCount()` | `{user:bool}` | 追蹤（全域，Profile/CreatorPage 共用） |
| `comments` / `addComment(postId,text)` | `{postId:[{user,text,mine}]}` | 留言 |
| `likedComments` / `toggleCommentLike(key)` | `{key:bool}` | 讚留言 |
| `balance` / `withdraw()` | number | 錢包餘額（Wallet/CreatorConsole 共用）；`withdraw` 歸零回 true |
| `prefs` / `setPref(k,v)` | `{notif,priv,textSize,reduceMotion}` | 偏好（**持久化** `localStorage('jq-prefs')`）。`textSize`('sm'/'md'/'lg') 與 `reduceMotion` 由 nav.jsx 套到 `<html data-textsize / data-reduce-motion>`，CSS 生效（lg=zoom 1.14） |
| `notifRead` / `setNotifRead(b)` | bool | 通知已讀（清鈴鐺紅點） |
| `toast` / `setToast(msg)` | string | 浮動提示（1.8s 自動消失） |

**眉角**：只有一個 Context provider → 任何狀態改變會重繪整棵樹（原型可接受；正式要拆 context / memo）。

## AR 掃描（`/AR`）— MindAR 官方 three.js 整合

> **2026-08-10 起**走 MindAR（`MindARThree`）。先前那套自研的「四角偵測＋dHash 比對」
> （`scanner.js`／`arTracker.js`／`quadDetect.js`）已退役，`/AR` 不再引用。

- `src/lib/mindarThree.js` — 官方 MindARThree 的**在地化版本**（原版 import 了 three 0.185
  已移除的 `sRGBEncoding`，會直接建置失敗）。演算法與座標約定一行未改。
- `src/lib/mindScene.js` — 唯一的接線層：把 3D 角色掛到 `anchor.group`、用 `Raycaster`
  把命中的熱區變成內容。`CALIB.vSign = -1` 是**量出來的不可推導**。
- `src/screens/Scan.jsx` — 只剩畫面與診斷面板（鏡頭挑選／自我測試／心跳）。
- 目標資料在 `public/ar/targets/`：`*.mind`（追蹤真正吃的特徵點庫）＋ `*.png`
  （`/ar/card/:slug` 備援頁底圖）。詳見該資料夾的 `README.md`。
- 影像全在裝置端運算、**不上傳**。
- 閘門：`scripts/check-mind.mjs`（95 項）掛在 `npm run build` 上。

`src/lib/scanner.js`（dHash＋直方圖）仍活著，但只被 `arCardRegistry.js` 使用，
不再是 `/AR` 的追蹤路徑。

## `src/data/almanac.js` — 農民曆引擎（確定性、無亂數）

- `ANCHOR = 2026/6/6`（= 芒種・丙午日，offset 0）。
- `dayFor(off)` → 某偏移日的**完整傳統日頁**（~30 欄）：
  - 天文/曆法：`{solar,weekday,term,festival,lunar,lunarMon,lunarDay,yearGZ,monthGZ,ganzhi,zodiac,wuxing(納音)}`
  - 宜忌/評分：`{yi[],ji[],luckyHours,stars,proverb}`
  - 擇日神煞：`{jianchu(建除),jianchuYi(宜忌註),xiu(星宿),xiuAnimal,xiuLuck,taishen(胎神),pengzu[2](彭祖百忌)}`
  - 沖煞：`chong{zodiac,gz,dir,ages[](虛歲三代)}`
  - 吉神方位：`{xishen(喜神),caishen(財神),guiren(貴神)}`
  - 時辰/特殊日：`hours12[12]{zhi,range,luck}`、`flags[]{t,d,good}`（天赦/受死/四離四絕/楊公忌/三娘煞/月忌…）
- `yearOverview`（年度總論卷首，物件）：`{ganzhi("丙午年"),year,zodiac,nayin,taisui{name,note},chunniu,dimu{poem,div},fanTaisui[5]{z,k,d},fangwei[5]{k,v,d},note}`。
- `dateFromOffset(off)` / `offsetFromDate(date)` / `monthCells(year,month)`（月曆格）。
- 全部**確定性演算**（無亂數）：月柱五虎遁、沖煞虛歲、建除由月建+日支、星宿連續週期。屬**擇日神煞層示範演算**（規則正確、非權威曆算），畫面均有 Disclaimer，正式應接 lunar-javascript／通書資料核對。消費畫面：`AlmanacDay`（`dayFor`）、`YearAlmanac`（`yearOverview`）、Feed 曆頁。
