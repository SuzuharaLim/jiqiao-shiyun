## 專案落實前提（務必先讀）

| 項目 | 決策 |
|---|---|
| 架構 | 現有 Vite + React 18 純前端 SPA → **新增 Node.js + Express 後端**，單一容器部署 Google Cloud Run |
| 傳輸安全 | HTTPS 由 Cloud Run 自動提供（TLS 終結在 Cloud Run 前端） |
| 資料庫 | **SQLite（better-sqlite3）**，同容器內檔案；⚠️ Cloud Run 檔案系統為暫存，重佈署/擴充即重置 → 正式須改 **Cloud SQL / Postgres** |

| 密碼 | **bcrypt**（cost ≥ 12，自帶 per-user salt） |

| Redis | 無 → 速率限制/鎖定計數暫存於 SQLite 或行程內存；正式建議 Redis |
