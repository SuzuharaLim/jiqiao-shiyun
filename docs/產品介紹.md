# 機巧時運 · 產品介紹

> **智慧互動農民曆 × 節氣攝影社群 × AI 時光顧問** — 一本會說話的文化手帳。
> 五位資工生的文化實驗；已上線於 **https://chengqi.tw**（Google Cloud Run + Cloud SQL）。

## 我們解決什麼問題

- 農民曆是台灣人的生活智慧，但**年輕世代看不懂、也不看**；節氣文化正在流失。
- 主流社群平台**去文化、去在地化**，好照片與節氣、土地的連結被稀釋。
- 傳統命理/擇日 App **只查不互動**，沒有社群、沒有創作、沒有陪伴。

## 我們的解法

把「農民曆」重新設計成一個**虛實整合、會互動的文化平台**：查得懂的曆頁、拍得出來的節氣、聊得起來的 AI 顧問，三者長在同一個 App 裡。

## 功能亮點

1. **完整農民曆引擎** — 任一日的三柱干支、建除十二神、二十八星宿、彭祖百忌、胎神、沖煞虛歲、財喜貴方位、十二時辰吉凶、特殊日；App 開在**真實今日**，年度總覽含太歲/地母經/犯太歲/凶方。全部確定性演算、可驗證。
2. **節氣攝影社群** — 貼文、按讚、留言、追蹤、作品市集與授權分潤，**全部真實存資料庫**、可持久化，刻意去 IG 化、走宣紙墨色美學。
3. **自研相機工作室** — 單點拍照/長按錄影、2–6 格拼貼、純文字限動（票選/問答/倒數）、滑動濾鏡、經典濾鏡＋強度滑桿、特效庫、**搖晃顯影**、動態文字（打字機/卡拉OK/霓虹）。**純瀏覽器 API、零第三方函式庫。**
4. **AI 時光顧問** — 對話式占卜、解宜忌、解夢；接上 GPT 後會帶入**今日節氣脈絡**回答。
5. **自研平面 AR 追蹤** — 偵測卡片四角 → 透視拉正 → 多視角簽名比對 → 解 homography 與
   6DoF 姿態，3D 角色貼合在卡面上並跟著傾斜。**零第三方相依、裝置端運算、影像不上傳**；
   `check-ar` 199 項＋`check-char` 57 項掛在 build 上。

## 技術亮點

- **全端一體**：React 18 + Vite 前端、Node/Express 後端、**PostgreSQL（Cloud SQL）** 資料庫，部署於 **Cloud Run**，已綁自訂網域 `chengqi.tw`。
- **真實資安**：bcrypt 雜湊、伺服器端 Session、CSRF、防列舉、帳號鎖定、速率限制、helmet CSP/HSTS、**RBAC 四級**、GDPR 刪帳/匯出。
- **工程品質**：內容全面資料庫化（非假資料）、**每頁獨立網址**（可分享/深連）、可移植資料層（pg/sqlite 雙驅動）、內容 CMS（資料可線上修改）、金鑰走 Secret Manager。
- **成本可控**：Cloud Run 閒置歸零；示範規模在免費額度內。
