# 附：樣式設計銳評（同日記錄，尚未動工）

實測數據：首頁同屏 20 種字號（10–56px）、emoji 每屏 14–17 個、
占卜頁 10 個粉彩底色元素、朱紅分布失衡（首頁 11 個 vs 占卜頁 1 個）。

1. **字級收斂**：全站寫死的 px 收斂到 tokens 的 7 階（--text-xs~4xl 已定義但幾乎沒用）；
   11px 以下只准用於徽章類非必讀資訊。
2. **Emoji 換單色線條圖示**：工具列/空狀態/按鈕的彩色 emoji 與紙感氣質斷層，
   擴充既有 Icon.jsx 的 SVG 系統取代。→ 氣質提升最大的單一改動。
3. **粉彩 tone 換紙感衍生色**：--tone-1~6 與各畫面寫死的 IG 粉彩
   （#dcfce7/#dbeafe/#fce7f3…）改為茶褐/竹青/赭石/黛藍淡染。
4. **深色紙紋穿幫**：雙向 repeating-gradient 在深色呈方格紙狀；
   透明度減半或深色停用紋理。
5. **朱紅配額**：每屏至多 3 個朱紅焦點；金/柳綠幾乎未用——
   可依四季節氣輪替第二點綴色（春柳綠/夏朱/秋金/冬黛）。
6. 零碎：靛青占卜卡是唯一殘存漸層（改黛藍紙底+金線框）；13px 奇數間距未用
   token 間距階；「宜 宜」標籤與內容重複渲染；品牌列用全形空格隔字應改 letter-spacing。

樣式修三件優先序：emoji→圖示、字級收斂、tone 換色。
