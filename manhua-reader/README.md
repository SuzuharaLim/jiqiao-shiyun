# 漫畫櫃連續滑動閱讀器（Google Apps Script 版）

把 [tw.manhuagui.com](https://tw.manhuagui.com) 「一頁頁點下一頁」改成 **一路往下滑就能看整話**，並用 **Google 試算表**存你的搜尋紀錄／觀看紀錄（含閱讀進度）／最愛／自訂名稱的收藏夾。全部跑在你自己的 Google 帳號裡，不用架伺服器、不用付費。

---

## 它怎麼解決你的問題

| 你的痛點 | 這個 App 的做法 |
| --- | --- |
| 每頁都要跳下一頁 | 章節整話圖片一次抓好，用**連續垂直捲動**呈現（IntersectionObserver 懶載，滑到哪載到哪）|
| 看完一話還要手動找下一話 | **章末自動接續下一話**（可在設定關閉），也有上一話／下一話按鈕與 ← → 鍵 |
| 想記錄看到哪 | 捲動時**自動存閱讀進度**到試算表；下次從書架／歷史點「續讀」回到該話 |
| 想存搜尋／最愛／分類收藏 | 都寫進 Google 試算表；收藏夾**名稱可自己建立、命名、刪除** |
| 圖片有防盜連（瀏覽器直接載會 403）| 圖片一律經 Apps Script 後端帶 `Referer` 抓取、轉 base64 回傳 |

**額外功能**：分類瀏覽（最新／熱門／日漫／港漫／國漫／少年／少女／完結）、可調圖片寬度與頁間距、單頁翻閱模式、點畫面中央隱藏/顯示工具列、鍵盤操作、封面懶載、圖片前端快取。

## 部署步驟（手機或電腦皆可，約 3 分鐘）

**只需要 2 個檔案**：一個程式檔 `Code.gs`（新專案本來就有）、一個網頁檔 `Index.html`（自己加）。

1. 開 <https://script.google.com> → **新增專案 / New project**。
2. 左邊本來就有一個 `Code.gs`：把裡面預設內容**全部刪掉**，貼上本資料夾 `Code.gs` 的內容。
3. 加網頁檔：左側「檔案 / Files」旁的 **＋** → 選 **HTML**（不是 Script）→ 命名 **`Index`**（不用打 `.html`，系統會自動補）→ 把本資料夾 `Index.html` 的內容整段貼進去。
4. 右上 **部署 / Deploy → 新增部署作業 / New deployment** → 齒輪選 **網頁應用程式 / Web app**：
   - 執行身分 / Execute as：**我 / Me**
   - 具有存取權 / Who has access：**只有我自己 / Only myself**
   - 按「部署」→ 第一次會要授權 → 選你的 Google 帳號 → 「進階 / Advanced → 前往（不安全）/ Go to (unsafe)」→ **允許 / Allow**。
     （3 個權限：連外抓 manhuagui、建立/讀寫你的試算表、顯示網頁。）
5. 複製「網頁應用程式」網址用瀏覽器打開。**手機**在瀏覽器選單按「加入主畫面」，就像一個 App。

第一次執行會**自動**在你的雲端硬碟建一張「漫畫閱讀器 · 資料庫」試算表，之後搜尋/觀看/最愛/收藏夾都存這裡。App 右上角 📊 可直接開它。

> ### 找不到「加入 JSON」？不用管它
> `appsscript.json`（資訊清單檔）**不是**用「＋」新增的，也**可以完全跳過**——Apps Script 會自動產生它，並在你第一次部署授權時自動要好需要的權限。
> 如果你想手動貼（非必要）：點左側齒輪 **專案設定 / Project Settings** → 勾 **「在編輯器中顯示 appsscript.json 資訊清單檔案」**，編輯器才會出現這個檔，再把本資料夾 `appsscript.json` 內容貼上。**新手直接略過即可。**

> ### 「＋」只有 Script 和 HTML 兩種
> Apps Script 的檔案只有這兩類：程式選 **Script**（副檔名 `.gs`）、網頁選 **HTML**（副檔名 `.html`）。沒有「JSON」選項是正常的。

## 操作說明

- **首頁**：上方分類籤切換榜單；點卡片進作品；卡片右上 🤍/❤️ 直接加/退最愛。
- **搜尋**：頂欄輸入送出（自動記錄到搜尋紀錄）。
- **作品頁**：▶ 開始/續讀、加入最愛、📁 加入收藏夾、點章節進閱讀器。
- **閱讀器**：往下滑即可；點畫面中央開關工具列；底部拉桿跳頁、上/下一話；⚙️ 調寬度/間距/模式/自動接續。
- **書架**：最愛 +（可命名的）收藏夾，收藏夾可新增/刪除、單品可移出。
- **歷史**：觀看紀錄（點「續讀」回到該話進度）＋搜尋紀錄（點籤再搜一次）。

## 疑難排解

- **「抓取失敗 (403/503)」或列表空白**：manhuagui 有時會擋 Google 伺服器 IP，或該分類路徑改版。先換個分類/關鍵字試；持續失敗多半是對方封鎖，非程式錯誤。
- **「無法解析章節圖片資料」**：manhuagui 章節頁的打包格式改版了。這版用的解法是 `LZString.decompressFromBase64` + dean-edwards packer；若對方改格式，需更新 `Code.gs` 的 `apiChapter` 正則。
- **圖片載很慢**：所有圖都經 Apps Script 中轉（因防盜連），本來就比直連慢；已用併發佇列(4)＋懶載＋快取緩解。Apps Script 免費帳號每天 UrlFetch 約 20,000 次，個人閱讀足夠。
- **改了程式沒生效**：Apps Script 要**重新部署**（部署 → 管理部署作業 → 編輯 → 版本選「新版本」）。

## 合法性與用途

這是**個人閱讀用的前端工具**：它只是把你本來就看得到的 manhuagui 頁面換一種呈現方式（連續捲動）並記錄你自己的閱讀狀態，不儲存、不散布漫畫檔案（圖片即時抓、即時看）。請自行遵守當地法規與該站服務條款，僅供個人使用。
